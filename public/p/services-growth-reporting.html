Do we need a data team for this?

No. Zoyare builds and runs the pipeline, and the report arrives as a message your team can read.

Can we keep our current dashboard tool?

Yes. The data lands in a database any dashboard tool can read.

Can agents connect to the tools we use?

Yes, when the tool has an API or an export. The quote lists every connection, so you know what is in scope.

Who owns the code and the workflows?

You do. At handover you get the code, the documentation and the runbooks, and any developer can continue with them.

How fast can the first agent go live?

A small automation is live in 2 to 6 weeks after the quote is signed. The timeline is fixed in the quote.

Where is our data stored?

On EU hosting, under a Dutch contract. Access is agreed per source before anything is connected.
