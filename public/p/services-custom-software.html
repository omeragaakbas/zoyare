Who owns the code when the project is done?

You do, always. You get the full source code, documentation and deployment setup, and any competent developer can continue the work.

Can it connect to the tools we already use?

Yes, and it usually should. Links with your accounting package, CRM, e-mail or databases are typically part of the scope.

Custom software or an off-the-shelf package?

If an existing tool covers 80% of what you need, buy it. Build custom when the process is core to how you win business, or when workarounds cost more than software would.

What if Zoyare is unavailable?

Every delivery includes documented code, automated tests and a handover that any developer can pick up.
