What can an agent decide by itself?

Only what you approve up front. Refunds, prices and exceptions wait for a person, and every action is logged.

Who runs the agents after launch?

Your choice. Zoyare can run and monitor them for you, or hand them to your own team with a runbook.

Can agents connect to the tools we use?

Yes, when the tool has an API or an export. The quote lists every connection, so you know what is in scope.

Which AI model does the agent use?

The model is picked per job and named in the quote, together with the data terms of its provider.

How fast can the first agent go live?

A small automation is live in 2 to 6 weeks after the quote is signed. The timeline is fixed in the quote.

What does custom software cost?

A small automation or tool costs 5,000 to 20,000 euro (2 to 6 weeks). A mid-sized system with integrations 20,000 to 75,000 euro (2 to 4 months). A platform or large app from 75,000 euro.

What does an agent cost?

A first agent is priced like a small automation, 5K to 20K euro to build. Running and monitoring it afterwards is a separate line in the quote.

How long does a typical project take?

A simple automation takes 2 to 6 weeks, an integration 2 to 8 weeks, and a mobile app or larger system 3 to 6 months for a solid MVP.

Fixed price or hourly rate?

Both are possible. A clearly scoped project gets a fixed price. Ongoing work or an unclear scope is fairer at an hourly rate, agreed up front.

What is the minimum project size?

There is no strict minimum, but under 3,000 euro custom work is rarely the smart choice. A no-code tool or existing package is then the better fit.

What does the first conversation look like?

A 30-minute call, free and without a sales pitch. You get advice on whether custom work fits, an approach and a rough price indication.

Does Zoyare work alone or with a team?

One engineer does the work, by design. Selected specialists join for design or a security audit, and responsibility stays with Zoyare.

How does communication work during a project?

Weekly updates, direct access by e-mail or chat, and sprint reviews where you see progress before delivery.

Can you extend or rebuild existing software?

Yes. First comes a review of the code, architecture and documentation, then an assessment: continue building or start fresh.

Which technologies do you use?

Node.js, TypeScript and PostgreSQL for back-ends and APIs. React Native with Expo for apps. Java and Mendix for enterprise integrations. Next.js and React for web.

Who manages the software after delivery?

That is agreed up front: you, your internal team, or Zoyare under a maintenance contract. The handover lets any developer continue.

Do I get the source code?

Always. The source code is fully yours, and you never depend on Zoyare for access to your own software.

How do you handle testing and quality?

Automated tests are part of every delivery. You get a staging environment to test on, and bugs that trace back to Zoyare's code get fixed.
